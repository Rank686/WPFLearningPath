# Step 40：分数转换预览

## 本项目巩固

在资料编辑闭环上复用具名对象资源，并把数值交给单向转换器显示等级。

## 运行后观察

拖动分数滑块时，原始分数与等级文字同时变化。

## 相比同轨上一步的改动

保留资料编辑闭环，加入具名对象资源和单向值转换。

## 已学并复用

资料 ViewModel、DataContext、即时双向 Binding、属性变化通知、x:Key 与 StaticResource。

## 固定脚手架

App 只指定启动窗口；资料对象与转换器保持在窗口资源范围。

## 源码中保证不存在

样式、合并资源字典、集合控件、命令与第三方 MVVM 框架。

## 完成后的综合练习

拖动滑块跨过 60、80、90 的边界，观察等级文字的变化。
