# Step 41：资源化资料编辑器

## 本项目巩固

把窗口资源、合并资源字典、显式 Style 与两种事件连接方式加入原有资料绑定和分数转换。

## 运行后观察

三个界面区域共享资源字典样式，保存与清空状态按钮都能工作。

## 相比同轨上一步的改动

保留绑定和转换，再把颜色、间距、显式 Style 与两种事件连接方式组合起来。

## 已学并复用

资料 ViewModel、DataContext、即时双向 Binding、转换器、x:Key、StaticResource、样式、资源字典与事件订阅。

## 固定脚手架

App 只指定启动窗口；所有页面资源都保持在 MainWindow 范围，清空事件在构造函数订阅。

## 源码中保证不存在

应用资源、集合控件、数据模板、命令与第三方 MVVM 框架。

## 完成后的综合练习

编辑资料和分数后点击保存，再点击清空状态，比较两种事件连接方式的结果。
